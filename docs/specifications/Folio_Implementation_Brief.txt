--- PAGE 2 ---
How to use this document
This brief is written for an AI coding assistant (Claude Code in VS Code) 
building the Folio platform from scratch. Every section is a concrete instruction 
set, not a description. Read the Design System section (§1–§4) first and establish 
all tokens and base components before building any screen. Then build screens 
in the order listed in §5 onward — each screen references the base components 
and should not require new design decisions.
Where a section says "see token X" or "use component Y", that token or 
component is defined earlier in this document. When you encounter an 
ambiguous layout choice, default to the principles in §3. When you encounter a 
missing piece of copy, use the voice guidelines in §4.
  Do not import any component library (shadcn, MUI, Ant Design, Radix ⚠
UI). Build every component from scratch using Tailwind utility classes. The 
design must not look like any existing component library.
  Stack: Next.js 14 (App Router), TypeScript, Tailwind CSS, Claude API (claude-⚑
sonnet-4-6), PostgreSQL via Prisma, Auth.js v5. Monorepo root is /folio.

SECTION 4
Voice & Copy Guidelines
Every string in the UI — buttons, empty states, toasts, labels, AI messages — 
follows these rules. Do not use placeholder text like "No books found." Write 
like a thoughtful person who loves books and respects the reader.
Tone
● Warm and direct. Not effusive. Not corporate.
● Sentence case everywhere — never ALL CAPS labels.
● No exclamation marks in UI chrome. Reserve them for genuine moments 
of celebration (completing a book, hitting a reading goal).
● Books and reading are taken seriously. The product does not condescend.
Empty states — examples
Empty TBR:        "Nothing on your list yet. The chat can help you find 
what's next." Empty Read:       "You haven't logged a finished book yet. Add 
one and it will live here." Empty chat:       "Ask anything. Your library, 
recommendations, a bookshop nearby." No search result: "Nothing for that 
search. Try a title, author, or ISBN."
Toasts — examples
Book added:        "Added to your library." Session logged:    "36 pages 
logged. You're on page 214." Gift reminder set: "Reminder set for 3 weeks 
before Sarah's birthday." Error:             "That didn't save. Try again."
AI assistant persona
The AI speaks as a knowledgeable reading companion. It does not say "Great 
question!" It does not over-explain. It is specific, direct, and sometimes 
opinionated. It references the user's actual books by title. It occasionally admits 
uncertainty ("I'm not certain of the exact publication date — worth checking").

5.4  Chat API integration
POST /api/chat Body: { messages: Message[], userId: string }  Server 
assembles context object before calling Claude:   - currentBook: { title, 
author, currentPage, totalPages, pace }   - recentlyRead: last 10 books 
(title, author, rating)   - tbrTop10: prioritised TBR list   - savedPlaces: 
user's bookshops and libraries   - userContext: decrypted private context 
profile (see §13)  System prompt injected server-side — user never sees it. 
Stream the response: use ReadableStream, render tokens as they arrive. If 
response contains ISBN references, automatically fetch and render BookCards 
for those ISBNs at message end.
